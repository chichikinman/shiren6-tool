# 『風来のシレン6』アイテム価格識別ツール
こちら→https://chichikinman.github.io/shiren6-tool/

価格候補の一覧から選択してアイテム候補を表示するWebアプリ（PWA対応）です。

価格を入力するタイプの識別ツールが面倒だったので作成しました。
スマホでの使用を想定しています。


### 主な使い方

1. **アイテムの種別を選ぶ**

   画面上部のタブから調べたい分類（**腕輪 / 草 / 巻物 / 壺 / 杖**）をタップします。


2. **状態（通常・祝福・呪い）を指定する**
   
   **「通常」「祝福 (×2)」「呪い (×0.87)」** の状態チップを切り替えます。

   選択中の状態に合わせて、買値・売値のボタン一覧およびアイテムの価格表示が自動計算されます。

   
3. **価格をタップして候補を絞り込む**
   
   **「買値」**または**「売値」** の欄から特定の価格をタップすると、該当する候補のアイテムのみが表示されます。
   
   同じ価格をもう一度タップするか、右上の**「全件に戻す」** をタップと絞り込みを解除できます。


5. **アイテムの識別状態を記録する**
   
   候補のアイテムをタップすると、背景が緑色に変化して **「✓ 識別済」** となります。

   候補のアイテムの入力欄には、仮名を自由にメモできます。草投げによる仮識別などに使います。

   メモや識別状態は端末内に自動保存されるため、タブを移動しても保持されます。


5. **壺・杖の残数による価格一覧**
   
   壺・杖は、候補のアイテムの欄に残数ごとの買値・売値が横スクロールで一覧表示されます。

   選択している絞り込み条件に一致している残数はオレンジ色でハイライトされます。


6. **識別済アイテムの表示切り替え（済: 表示 / 済: 除外）**
   
   **「済: 表示中」** をタップして **「済: 除外中」** に切り替えると、 **「✓ 識別済」** にしたアイテムを検索結果から非表示にできます。
   
   ※誤タップ防止のため、タップした直後はその場に残り、タブの切り替えや価格の再選択を行ったタイミングで画面から除外されます。


7. **データの消去・リセット**

   **「タブ消去」**: 現在開いているタブのみをリセットします。

   **「全消去」**: すべてのタブをリセットします。新しい冒険を始める際に使用します。


### アイテム名の文字色について
　**ピンク色**: ゲーム内で入手した時点で自動的に識別済となるアイテム（白紙の巻物、ビックリの壺 等）
 
　**青色**: 「とぐろ島の神髄」では出現しないアイテム（脱出の巻物、ねだやしの巻物、罠師の腕輪 等）


### アプリとしてホーム画面に追加する方法（PWA）

1. スマホのブラウザ（Chrome推奨）でこのページを開きます。
2. ブラウザメニュー（右上の「︙」など）を開きます。
3. **「ホーム画面に追加」**（または「アプリをインストール」など）を選択します。
4. ホーム画面に専用アイコンが生成され、ブラウザ枠のない全画面表示＆オフラインでプレイできます。

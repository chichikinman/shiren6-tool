『風来のシレン6』アイテム価格識別ツール
https://chichikinman.github.io/shiren6-tool/
ダンジョン内の店や買値・売値からアイテムを素早く特定・管理できるWebアプリ（PWA対応）です。
スマートフォン1台での片手操作に最適化しており、オフライン環境でも動作します。

---

### 主な使い方

1. **アイテムの種別を選ぶ**
* 画面上部のタブから調べたい分類（**腕輪 / 草 / 巻物 / 壺 / 杖**）をタップします。


2. **状態（通常・祝福・呪い）を指定する**
* アイテムの状態に応じて **「通常」「祝福 (×2)」「呪い (×0.87)」** のチップを切り替えます。


* 選択中の状態に合わせて、買値・売値のボタン一覧および候補内の価格表示が自動計算されます。




3. **価格をタップして候補を絞り込む**
* 店の販売価格なら **「買値」**、店主に売却する価格なら **「売値」** のボタンをタップすると、該当するアイテムのみが瞬時に表示されます。
* 同じボタンをもう一度押すか、**「全件に戻す」** を押すと絞り込みを解除できます。


4. **アイテムの識別状態を記録する**
* 候補アイテムの枠（名前部分）をタップすると、背景が緑色に変化して **「✓ 識別済」** となります。
* 入力欄には、ゲーム内で表示されている仮名（例: *あおい草*、*木製の壺* 等）を自由にメモできます。
* メモや識別状態は端末内に自動保存されるため、タブを移動したりブラウザを閉じても保持されます。


5. **壺・杖の残数を確認する**
* 壺（容量0〜5）および杖（回数0〜7）は、現在選択している状態（通常/祝福/呪い）に応じた残数ごとの買値・売値が横スクロールで一覧表示されます。


* 絞り込み条件に一致している残数はオレンジ色でハイライトされます。


6. **識別済アイテムの表示切り替え（済: 表示 / 済: 除外）**
* **「済: 表示中」** をタップして **「済: 除外中」** に切り替えると、識別済にしたアイテムを検索結果から非表示にできます。
* ※誤タップ防止のため、タップした直後はその場に残り、タブの切り替えや価格の再選択を行ったタイミングで画面から除外されます。


7. **データの消去・リセット**
* **「タブ消去」**: 現在開いているタブの識別状態・仮名メモのみをリセットします。
* **「全消去」**: すべてのカテゴリのデータを初期化し、新しい冒険を始める際にリセットします。



---

### アイテム名の文字色について

* **赤色（ピンク色）**: ゲーム内で入手した時点で自動的に識別済となるアイテム（白紙の巻物、ビックリの壺 等）


* **青色**: 高難度ダンジョン「とぐろ島の神髄」では出現しないアイテム（脱出の巻物、ねだやしの巻物、罠師の腕輪 等）



---

### アプリとしてホーム画面に追加する方法（PWA）

1. スマホのブラウザ（Chrome推奨）でこのページを開きます。
2. ブラウザメニュー（右上の「︙」など）を開きます。
3. **「アプリをインストール」**（または「ホーム画面に追加」）を選択します。
4. ホーム画面に専用アイコンが生成され、ブラウザ枠のない全画面表示＆オフラインで快適にプレイできます。
